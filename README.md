> Selenium tabanlı otomasyonda proxy bağlantısı kullanımı üzerine hazırlanmış deneysel bir çalışma.

## 📌 Proje Hakkında

`Proxdlldeneme`, web otomasyonu sırasında proxy yapılandırmasının nasıl ele alınabileceğini incelemek amacıyla oluşturulmuş bir deneme projesidir.

## ✨ Konular

- Proxy yapılandırması
- Selenium otomasyonu
- WebDriver bağlantı ayarları
- Ağ yapılandırması ile otomasyonun birlikte kullanılması

## 🧰 Teknoloji Kartları

| Teknoloji | Rol |
|---|---|
| 💻 **C# / .NET** | Uygulama |
| 🧪 **Selenium** | Web otomasyonu |
| 🌐 **HTTP/HTTPS Proxy** | Ağ yönlendirme |

## 🚀 Başlangıç

```bash
git clone https://github.com/ebubekirbastama/Proxdlldeneme.git
```

Proxy bilgilerini kaynak koduna sabitlemek yerine güvenli yapılandırma yöntemi kullanılması önerilir.

## ⚠️ Proje Durumu

Legacy/experimental çalışmadır. Modern kullanım için WebDriver sürüm yönetimi, timeout, retry, proxy doğrulama ve yapılandırma dosyası desteği eklenmelidir.

## 🔐 Etik Kullanım

Proxy ve otomasyon yalnızca yetkili web testleri ve kendi sistemleriniz üzerinde kullanılmalıdır. Platformların kullanım şartlarına uyun.
